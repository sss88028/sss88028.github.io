# Jack Tu

一位擁有 11 年專業開發經驗的資深軟體工程師，深耕於遊戲開發（9年）與半導體自動化設備軟體研發（1.5年）。我以 C++ 與 C# 為核心技術，具備跨越遊戲引擎底層、跨平台 SDK、全端系統架構以及 AI 演算法整合的綜合研發能力。

在我的職涯中，我熱衷於透過優秀的軟體工程實踐來提升產品品質與團隊效率。我曾導入 ECS、MVC 等架構主導核心系統設計，並透過多執行緒與底層演算法優化，成功為 3D 遊戲與工業點膠系統解決嚴苛的效能瓶頸（如 FPS 最佳化與高 UPH 產能提升）。此外，我具備豐富的「工具魂」，善於利用 Python 與 AI 技術開發自動化工具來最佳化團隊的開發工作流。

我重視 Clean Code、TDD 與 CI/CD 流程，並擁有優異的跨團隊與跨文化溝通能力。我持有日檢 JLPT N1 證書，並能流利使用英語進行技術探討。
