## Kulicke & Soffa（クーリック・アンド・ソッファ）

**現職 | ソフトウェアエンジニア**

### 会社について

- Kulicke & Soffa (K&S) は、半導体および産業用ディスペンス装置の世界的リーダーです。
- ディスペンスは、マイクロエレクトロニクスや半導体プロセスにおいて、接着剤やシーラントをミクロン精度で塗布し、ダイ接着・封止・保護などに用いられます。

### 業務内容

ソフトウェア R&D チームに所属し、ディスペンス装置向けの制御・GUI ソフトウェア **V2K** の開発・保守を担当。

- **技術スタック**：C# / .NET (WinForms), Python, SQL
- **担当領域**：大規模レガシーの保守・不具合修正、新モジュールのアーキテクチャ設計と機能開発。

#### 1. コアシステムの最適化と安定性

- **リファクタリングとクリーンコード**：長年保守されてきた V2K をモジュール化し、**デザインパターン**を導入して可読性・保守性を向上。
- **UPH（時間あたり生産台数）**：工場での **24 時間連続稼働**でも低遅延・高安定を維持するようスループットを最適化。

#### 2. AI 連携と機能開発

社内の **AI／画像認識** を V2K に統合し、ワークフローと UI を設計。

- **Auto Parameter Tuning (APT)**  
  - **課題**：FAE が経験則で数時間かけてパラメータ調整していた。  
  - **対応**：機台物理量とディスペンス結果を自動収集し、バックエンドの AI 解析と連携して **ワンクリック最適化** を実現。導入時間を短縮。V2K の差別化要素の一つ。

- **Underfill AI Wizard**  
  - **課題**：Underfill は流体挙動に依存し、待ち時間の精度が UPH に直結する。  
  - **対応**：画像認識チームと協働し、目視確認を **コンピュータビジョン** に置き換え。**ウィザード UI** と動的制御ロジックを設計し、タイミング精度とラインサイクルを改善。

#### 3. 自動化とツール

- 週次のバグ残件集計・分析を **Python** で自動化（AI 支援の分析・レポート生成）し、チームの事務工数を削減。

## Fantasy Castle（奇幻城堡）

**2021 年 4 月 – 2024 年 9 月 | シニアソフトウェアエンジニア**

- **プロダクト**：モバイル向けカード／経営シミュレーション（*BigWar / Richman Fight*）
- **技術**：Unity, C#, MySQL, Photon Server, Entity Framework

### 主な成果

- **コア UI フレームワーク**：**MVC** ベースのテスタブルでイベント駆動の UI 基盤を主導し、Unity での UI 開発効率を向上。
- **CI/CD（Jenkins）**：自動ビルドを導入し Google 要件に追従。手動パッケージングを **40 分以上から 20 分未満** に短縮し、日次実行でイテレーションを加速。
- **パフォーマンスとマルチスレッド**：端末別チューニング、**マルチスレッド** と非同期処理で低スペック端末でも **30 FPS** を維持。C# `async/await` の活用を推進。
- **シェーダー**：エフェクト制作と旧シェーダー最適化で GPU 負荷を低減。
- **TDD**：テストプロセスを導入し品質を安定化。
- **バックエンドと DB**：クライアント–サーバー API と DB 設計。**CRUD 形式の Web API** で拡張性を確保。

## XRSpace

**2019 年 11 月 – 2021 年 4 月 | シニアソフトウェアエンジニア（System Framework Team）**

- **プロジェクト**：XRSPACE MANOVA / VR プラットフォーム SDK
- **技術**：Unity, Android Studio, C#, C++, Java
- **ミッション**：Android、Java、C++、Unity を横断し、第三者アプリが社製 Android 系 VR デバイス上で安定動作する SDK を提供。

### 主な成果

- **システム UI**：電源・音量などシステム機能。**Unity 3D UI** を透明な Android アプリに合成し没入型 UX を実現。
- **3D バーチャルキーボード**：Android `InputMethodService` を用いた VR 向けキーボードと文字入力。
- **投影最適化**：Unity の描画結果を取得し、両眼 VR を **シングルビュー** に変換して投影。非 VR 視聴者向けの視認性を改善。

## 競峰国際 (JFIGames)

**2017 年 3 月 – 2019 年 9 月 | ソフトウェアエンジニア（プロダクト開発チーム）**

- **技術**：Unity, PostgreSQL, Photon Server, C#, SQL, PHP, C/C++

### 参画プロジェクト 1：SuperAcornCup（3 対 3 パーティゲーム、2017/12～2018/12 リリース）

- **アーキテクチャ**：Overwatch 型を参考に **ECS** と **Entitas** でコアロジックを構築。
- **同期と物理**：**Lockstep**。**Bullet Physics** をサーバー側で用い物理を厳密に再現。
- **Bullet 最適化**：C# 環境でのボトルネックを底層から調整。
- **プレイヤーコントローラ**：段差・斜面での移動、**レイキャスト** 簡略化によるモバイル向け高速化。
- **投擲ロジック**：磁力概念により、斜面でも地面に沿った挙動を実現。

### 参画プロジェクト 2：モバイル経営ゲーム（2016/12～開発中）

- **UI とバックエンド**：装飾・アップグレード等、初期 UI アーキテクチャ、検証、**PostgreSQL** 永続化。
- **クエスト／イベント／AI**：**ビヘイビアツリー** 型のクエスト・イベントと NPC AI。
- **LBS**：第三者データ連携とコアロジック。
- **Web API**：運用向けデータ参照など。
- **カメラ**：俯瞰のパン・ズーム操作。

### プロトタイプ

- **大量ユニット回避**：**NavMesh** と **ORCA** で衝突回避、**30 FPS 以上** を維持。
- **ランダムマップエディタ**：データ駆動のマップと企画向けエディタ。
