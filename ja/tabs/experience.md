## Kulicke & Soffa（クーリック・アンド・ソッファ）

**現職 | ソフトウェアエンジニア**

### 会社について

- Kulicke & Soffa (K&S) は、半導体および産業用ディスペンス装置の世界的リーダーです。
- ディスペンスは、マイクロエレクトロニクスや半導体プロセスにおいて、接着剤やシーラントをミクロン精度で塗布し、ダイ接着・封止・保護などに用いられます。

### 業務内容

ソフトウェア R&D チームに所属し、ディスペンス装置向けの制御・GUI ソフトウェア **V2K** の開発・保守を担当。

- **技術スタック**：C# / .NET (WinForms), Python, SQL
- **担当領域**：大規模レガシーの保守・不具合修正、新モジュールのアーキテクチャ設計と機能開発。

#### 1. コアシステムの最適化と安定性

- **リファクタリングとクリーンコード**：長年保守されてきた V2K をモジュール化し、**デザインパターン**を導入して可読性・保守性を向上。
- **UPH（Units Per Hour／時間あたり生産台数）**：最大スループットを追求するため、時間のかかるロジックとシステム応答速度を最適化し、工場での **24 時間連続稼働**下でも高い安定性と低遅延を維持。

#### 2. AI 連携と機能開発

社内の **AI／画像認識** を V2K に統合し、スムーズなユーザー操作フロー（Workflow & UI）を設計。

- **Auto Parameter Tuning (APT)**  
  - **課題**：FAE が経験則で数時間かけてディスペンスパラメータを手動調整していた。  
  - **対応**：APT モジュールを開発し、機台物理量とディスペンス結果を自動収集、バックエンドの AI 解析と連携して **ワンクリック最適化** を実現。FAE の導入時間を大幅に短縮。

- **Underfill AI Wizard**  
  - **課題**：Underfill は流体挙動に依存し、待ち時間の精度が UPH に直結する。  
  - **対応**：画像認識チームと協働し、目視確認を **コンピュータビジョン** に置き換え。**ウィザード UI** と動的制御ロジックを設計し、タイミング精度とラインサイクルを改善。

#### 3. 自動化とツール

- 週次のバグ残件集計・分析を **Python** で自動化（AI 支援の分析・レポート生成）し、チームの事務工数を削減。

## Fantasy Castle（奇幻城堡）

**2021 年 4 月 – 2024 年 9 月 | シニアソフトウェアエンジニア**

- **プロダクト**：モバイル向けカード／経営シミュレーション（*BigWar / Richman Fight*）
- **技術**：Unity, C#, MySQL, Photon Server, Entity Framework

### 業務内容と主な成果

- **コア UI アーキテクチャとアート分離（MVC アーキテクチャリファクタリング）**  
  - **解決した課題**：UI とゲームロジックの密結合（Tight Coupling）により、UI 変更が不具合を招きやすかった。  
  - **具体実装**：**MVC** ベースのイベント駆動 UI へリファクタリングを主導。データ状態（Model）を独立管理し、Event／UniRx で UI を自動更新。抽象 Base Class を設計し、アーティストが Editor 上で UI バインド・調整を行え、コアロジックに触れないようにした。  
  - **成果**：プログラムとアートの **完全分離と並行開発（Parallel Workflow）** を実現し、統合効率を大幅に向上。

- **自動テストと品質保証（TDD & ユニットテスト）**  
  - システムロジックと UI を徹底分離したうえで、**ユニットテスト** と **テスト駆動開発（TDD）** をチームに導入。早期の不具合防止と自動検証により、リリース品質を大幅に向上。

- **シェーダー描画と低スペック端末最適化（Noise Shader & Low-end Optimization）**  
  - **技術的取り組み**：高品質な水面の波しぶき表現のため、高負荷な **Noise（ノイズ）** 演算を深く調査し、複数アルゴリズムのプロトタイプを試行錯誤。  
  - **成果**：画質と GPU 負荷のバランスを達成し、**最低スペック目標テスト端末（Low-end Target Device）** でも **30 FPS** の安定動作を維持。

- **CI/CD 自動ビルド（Jenkins Integration）**  
  - Jenkins による自動ビルドを導入し、プラグインと Google アプリの最新要件に追従。手動パッケージングを **40 分以上から 20 分未満** に短縮し、日次自動実行でイテレーションを加速。

- **マルチスレッドとパフォーマンス調整（Multi-Threading & Async）**  
  - 複数端末向けにシステム性能を最適化。**マルチスレッド** で時間のかかる処理を非同期化し、C# `async/await` の活用をチームに指導してメインスレッド負荷を低減。

- **バックエンド Web API と DB 設計（Server-Client API & DB）**  
  - Server／Client 通信 API を設計・実装。サーバー側ロジックと **データベーススキーマ（Database Schemas）** の設計・管理を担当。**CRUD 形式の Web API** を整備し、拡張と運用保守を容易にした。

- **プロジェクト**：XRSPACE MANOVA / VR プラットフォーム SDK
- **技術**：Unity, Android Studio, C#, C++, Java
- **ミッション**：Android、Java、C++、Unity を横断し、第三者アプリが社製 Android 系 VR デバイス上で安定動作する SDK を提供。

### 主な成果

- **システム UI**：電源・音量などシステム機能。**Unity 3D UI** を透明な Android アプリに合成し没入型 UX を実現。
- **3D バーチャルキーボード**：Android `InputMethodService` を用いた VR 向けキーボードと文字入力。
